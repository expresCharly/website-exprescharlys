# Expres Charlys — Sitio estático con Vite

Instrucciones rápidas para ejecutar el proyecto en modo desarrollo con Vite.

- Instalar dependencias:

```bash
npm install
```

- Iniciar servidor de desarrollo:

```bash
npm run dev
```

Vite servirá `index.html` en http://localhost:5173 por defecto. Si necesitas otro puerto, usa `npx vite --port 3000` o configura `VITE` según tu entorno.
